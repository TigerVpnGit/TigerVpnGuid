# 🐯 Tiger VPN

Welcome to the official repository of **Tiger VPN**. This project is a modern, fast, and secure portal providing step-by-step guides for setting up VPNs across various operating systems (Android, iOS, Windows, macOS, and Linux).

## ✨ Features
- **Multilingual Support:** Available in English, Farsi (Persian), and Russian.
- **Modern UI:** Built with Tailwind CSS, featuring Glassmorphism and Neon effects.
- **Dark/Light Mode:** Fully responsive and customizable themes.
- **Comprehensive Guides:** Easy-to-follow tutorials for bypassing restrictions.

## 🛠️ Tech Stack
- Framework: [Next.js](https://nextjs.org/)
- Styling: Tailwind CSS
- Icons: FontAwesome
- Deployment: GitHub Pages

## 🚀 Quick Start

To run this project locally:

```bash
# Install dependencies
npm install

# Run the development server
